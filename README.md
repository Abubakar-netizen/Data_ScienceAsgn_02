
The Urban Environmental Intelligence Challenge, focused on large-scale air quality analytics for smart city systems.

This project utilized real-time 2025 OpenAQ data from 100 global sensors, requiring scalable data processing, honest data visualization, and strict analytical integrity.

🔹 Task 1 and Task 2 — completed by Mubashra Afzal:

These tasks focused on Principal Component Analysis (PCA) based dimensionality reduction and high-density temporal analysis to identify daily and seasonal pollution patterns across multiple regions.

🔹 Task 3 and Task 4 — completed by  member Abu Bakar:

These tasks centered on statistical distribution modeling for extreme PM2.5 events and visual integrity auditing, where misleading three-dimensional visualizations were rejected in favor of perceptually accurate and ethically sound alternatives.

The complete solution was developed as a modular Python pipeline, optimized using Dask for scalable computation, and delivered through an interactive Streamlit dashboard.
